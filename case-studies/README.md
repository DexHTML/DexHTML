# Кейсы проектов

Публичная витрина проектов: реальные задачи, принятые решения, технологии, проверяемые результаты и границы применения. Описания приведены на русском языке; исходники внутренних систем остаются закрытыми.

## Внутренние системы

- **[TechRepair — учёт техники и ремонтов](TECHREPAIR.md)** — действующая внутренняя система: массовый приём, QR-выдача, ремонты, защита данных, резервное копирование, Linux/Windows установка и обновление; кандидат `1.0.0-rc.1` ещё проходит релизную приёмку.
- [FairDesk / ServiceHub](FAIRDESK.md) — внутренняя система заявок, назначения и интеграции независимых модулей.
- [Duty Schedule](DUTY_SCHEDULE.md) — production-система графиков и доступности сотрудников; текущий release 2.0.1.

Эти проекты используют закрытый исходный код. Публичные case studies содержат только безопасное описание архитектуры, функций, проверок и статуса без production-данных, внутренних адресов и секретов.

## Архитектура внутренних модулей

- **TechRepair** — source of truth по технике и ремонтной истории;
- **FairDesk** — заявки, workflow, исполнители и нагрузка;
- **Duty Schedule** — календарь, дежурства и доступность сотрудников;
- **ServiceHub** — будущая общая точка входа и навигации.

Модули остаются независимыми и интегрируются через ограниченные контракты вместо объединения в один монолит.

## Назначение витрины

Материалы подходят для портфолио, резюме, сопроводительных писем и обсуждения проектов с работодателями.
