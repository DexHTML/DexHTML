# Код полуночи

## Работающий Telegram-продукт с версионируемой контентной архитектурой

**Статус:** working production MVP, controlled expansion продолжается  
**Версия приложения:** 0.18.0  
**Активный content package:** 0.1.17  
**Формат:** закрытая реализация / публичный case study

«Код полуночи» — персональный Telegram-продукт внутри авторского мира «Карта в полночь».

Пользователь получает бесплатный персональный результат, а для поддерживаемых сценариев может открыть полную расшифровку. Основная механика, контентная библиотека, точные правила расчёта и производственные данные публично не раскрываются.

---

## Текущий production-сценарий

Telegram V2 поддерживает:

- расчёт контентного сценария по дате рождения;
- бесплатный результат из двух сообщений;
- безопасный unavailable-сценарий для ещё не покрытых дат;
- Telegram Stars invoice;
- persistent entitlement после оплаты;
- полную расшифровку через меню из пяти глав;
- повторное открытие уже приобретённого полного результата;
- безопасные агрегированные runtime-метрики.

Проект не требует классической регистрации и не хранит дату рождения как постоянный профиль пользователя.

---

## Контентная архитектура

Контент отделён от runtime-кода и поставляется versioned packages.

Активный production package `0.1.17` содержит 12 утверждённых golden cases.

Система включает:

- manifest как источник истины состава пакета;
- схемы и validators;
- контроль версии;
- content integrity checks;
- редакционные метаданные;
- controlled draft workflow;
- отдельное утверждение editorial и technical readiness;
- active/previous package и rollback boundary.

Новый материал не попадает в production автоматически. Expansion проходит отдельными case-scoped slices и требует подтверждения структуры, provenance и редакционного качества.

---

## Production и надёжность

Бот работает как отдельный Linux service.

В production подтверждены:

- systemd runtime;
- автоматический запуск;
- controlled deploy-copy;
- healthcheck;
- release check;
- rollback boundary;
- журналирование;
- backup/restore проверки;
- разделение code archive и private/runtime data;
- отсутствие секретов и runtime databases в Git.

Production deployment не зависит от наличия `.git` на сервере: provenance проверяется через deploy manifest и release checks.

## Тестирование и CI

На последнем полном hardening-checkpoint:

- **476 unit/structural tests — OK** в изолированном Ubuntu-окружении;
- Telegram V2 repository healthcheck — OK;
- release check — passed;
- platform-specific locking/file-mode/deploy checks выполняются в Ubuntu CI.

CI проверяет закреплённые зависимости, полный test suite, Telegram V2 healthcheck и release contract.

---

## Privacy boundary

В постоянный runtime profile не сохраняются:

- дата рождения;
- исходный пользовательский текст;
- полный текст персональной расшифровки.

Entitlement и metrics используют минимальный набор технических данных, необходимый для доступа и агрегированной эксплуатации.

Перед расширением пользовательской истории или аналитики privacy boundary пересматривается отдельно.

## Архитектура бренда

Проект входит в связанный авторский мир:

- **«Карта в полночь»** — публичный сайт и родительский content layer;
- **«Тринадцатая Карта»** — Telegram-канал;
- **«Код полуночи»** — персональный Telegram-продукт.

Бот является отдельным продуктом, а не просто дополнительной страницей сайта.
